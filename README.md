# Inmobiliaria_Conaltura_Frontend
Aplicación web para la inmobiliaria Conaltura que permita consultar, explorar, filtrar y visualizar inmuebles disponibles para venta y arriendo en Medellín y sus alrededores.  La aplicación consume una API REST proporcionada por la inmobiliaria y presenta la información de manera organizada, intuitiva y visualmente atractiva.
